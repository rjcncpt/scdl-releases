# SC Deutsch Launcher — Releases

Hier liegen die Installer des **SC Deutsch Launcher**, der die deutsche
Übersetzung für Star Citizen verwaltet. Der Quellcode liegt nicht in diesem
Repository.

## Download

Die jeweils neueste Fassung:

**[scdlauncher_setup.exe](https://github.com/rjcncpt/scdl-releases/releases/latest/download/scdlauncher_setup.exe)**

Ein manueller Download ist nur beim ersten Mal nötig — danach meldet sich der
Launcher selbst, sobald eine neue Version vorliegt.

## Was in einem Release liegt

| Datei | Zweck |
|---|---|
| `scdlauncher_setup.exe` | Installer für Windows |
| `hash_setup_neu.txt` | SHA-256 des Installers zum Nachprüfen |
| `release.txt` | Versionsstand, den der Launcher abfragt |
